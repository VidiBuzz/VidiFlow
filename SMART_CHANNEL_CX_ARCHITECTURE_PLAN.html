01. Executive Summary

Mission: Build Smart Channel CX, a browser-based video editing platform with Frame.io-style collaboration, powered by AI/ML pipelines and integrated with the existing Vidi ecosystem (VidiFlow, VidiShop, VidiCity, Visual Vector Omni Search).

Project Vision

Smart Channel CX represents the convergence of professional video editing, AI-powered content generation, and intelligent search capabilities. The platform enables users to edit MP4 files directly in the browser while leveraging a powerful media pool stored in Cloudflare R2, with real-time collaboration features inspired by Frame.io.

Key Capabilities

  • Browser-Based Video Editing: Full MP4 editing (trim, cut, split, transitions, text overlays, audio mixing, filters) powered by Remotion
  • AI-Powered Effects: Integration with ComfyUI and Stable Diffusion for generative video effects
  • Smart Graphics Generation: Gemini API integration for automated graphics and thumbnail creation
  • Visual Vector Omni Search: BM25 + Vector + Graph RAG + Geospatial search for content discovery
  • Frame.io-Style Collaboration: Time-stamped comments, version control, review workflows
  • Multi-Brand Support: VidiShop integration for personalized shopping experiences
  • Local News Portal: VidiCity geospatial video news platform integration
  • Knowledge Base: AppFlowy (VidiFlow) integration for faceted content creation

Target Users

  • Content creators and video editors
  • Marketing teams managing video campaigns
  • Local news organizations (VidiCity)
  • E-commerce businesses (VidiShop)
  • Agencies requiring client collaboration

7 Specialized Agents

📥

Agent 01: Media Ingestion Agent

media-ingestion-agent

Handles MP4 uploads to Cloudflare R2, extracts metadata, generates variants, creates thumbnails, triggers transcription

Tools: FFmpeg.wasm, Whisper API, R2 SDK

✂️

Agent 02: Edit Assistant Agent

edit-assistant-agent

Processes edit operations, builds EDLs, optimizes render pipelines, suggests edit points via scene detection

Tools: Remotion Player, Scene Detection ONNX Model

🎨

Agent 03: Graphics Generation Agent

graphics-gen-agent

Generates AI graphics from prompts, creates lower thirds, thumbnails, style transfer via ComfyUI

Tools: Gemini API, ComfyUI API, Stable Diffusion

💬

Agent 04: Collaboration Agent

collaboration-agent

Manages Frame.io-style comments, real-time sessions, version control, notifications, share links

Tools: WebSockets, Cloudflare D1, Notification Service

🔍

Agent 05: Search Index Agent

search-index-agent

Extracts visual embeddings, indexes transcription, builds knowledge graphs, geospatial tagging

Tools: CLIP Model, Neo4j, Pinecone/Weaviate, PostGIS

✅

Agent 06: Quality Control Agent

quality-control-agent

Validates exports, checks A/V sync, verifies color space, detects copyright issues, ensures accessibility

Tools: FFmpeg validation, Audio fingerprinting ONNX models

🎬

Agent 07: Export Render Agent

export-render-agent

Queues render jobs, distributes across workers, applies compositing, generates multiple formats

Tools: Remotion Lambda, FFmpeg, R2 SDK

04. Technology Stack

Frontend Layer

⚛️ Next.js 14 (App Router)

React framework with server components, streaming SSR, and edge runtime support

🎬 Remotion

Programmable video editing in React. Core engine for timeline, preview, and rendering

🎨 TailwindCSS + Framer Motion

Utility-first styling and animations for Frame.io-inspired dark theme

📹 FFmpeg.wasm

Browser-based video processing for client-side operations

Edge & Serverless Layer

☁️ Cloudflare Workers

Edge compute for API routing, auth, and WebSocket handling

🦀 Rust + Astro

High-performance API gateway. WASM-compatible for ONNX models

🗄️ Cloudflare D1

SQLite-based edge database for projects and collaboration state

⚡ Cloudflare KV

Key-value store for session data and real-time collaboration

Storage & CDN

📦 Cloudflare R2

S3-compatible object storage. Zero egress fees for media delivery

🌐 Cloudflare CDN

Global content delivery for video segments and assets

🔄 TUS Protocol

Resumable upload protocol for large video files

AI/ML Services

🧠 ComfyUI

Node-based Stable Diffusion interface for AI video effects and graphics

🔮 Google Gemini API

Multimodal AI for graphics generation and content analysis

⚙️ ONNX Runtime

Cross-platform ML inference for scene detection and quality analysis

🎯 CLIP/BLIP Models

Vision-language models for content understanding and indexing

Search & Analytics

🔍 Meilisearch/Typesense

BM25 keyword search with typo tolerance and faceting

🧮 Pinecone/Weaviate

Vector database for semantic similarity search

🕸️ Neo4j

Graph database for RAG and recommendation engines

🗺️ PostGIS

Geospatial extension for VidiCity location-based search

ComfyUI Deployment Options

  • Option A - Self-Hosted: Run ComfyUI on GPU instances (RunPod, Vast.ai)
  • Option B - Serverless: Use ComfyUI API via Fal.ai or Replicate
  • Option C - Hybrid: Lightweight inference at edge, heavy generation in cloud

Image Capabilities Summary

❌ What I Cannot Do: Generate new images directly

07. Implementation Roadmap

Phase 1: Foundation (Weeks 1-4)

  • Initialize Next.js 14 project with Remotion
  • Configure Cloudflare R2 and Workers
  • Build Remotion-based timeline and player
  • Upload pipeline with TUS protocol

Phase 2: Editing Features (Weeks 5-8)

  • Advanced editing (split, merge, transitions)
  • Text overlays and audio tracks
  • Export pipeline and render queue
  • Project save/load with auto-save

Phase 3: AI Integration (Weeks 9-12)

  • Deploy ComfyUI server
  • Integrate Gemini API
  • AI effects pipeline and style transfer
  • Graphics generation workflows

Phase 4: Search & Integrations (Weeks 13-16)

  • Omni Search implementation
  • AppFlowy (VidiFlow) integration
  • VidiShop product tagging
  • Vector and graph indexing

Phase 5: Collaboration & Polish (Weeks 17-20)

  • Frame.io-style collaboration features
  • VidiCity geospatial integration
  • Performance optimization
  • Production deployment
