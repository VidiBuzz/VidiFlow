VIDIFLOW STATUS ORB

State-driven glowing orb that changes color and animation based on agent status. Each state has unique visual properties:

  • ● IDLE - Slow pulse, dim glow
  • ● THINKING - Medium pulse, cyan glow, 2 rings
  • ● RUNNING - Fast pulse, green glow, 3 rings
  • ● HOT - Fast pulse, amber glow, 3 rings
  • ● ERROR - Very fast pulse, red glow, 4 rings
