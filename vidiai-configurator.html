THE LANE
BATTLE

Visual lane mapping. Professional boards guarantee x16 speed on all slots, eliminating data traffic jams.

Air Gap Strategy - Slots 1, 3, 5, 7

When installing 4 GPUs in a 7-slot chassis, use slots 1, 3, 5, and 7. This leaves one empty slot between each card, creating an air gap that prevents heat from one GPU from being sucked into the next card's intake.

Blower cards pull air from the front and exhaust it directly out the rear. Air gaps prevent heat recirculation between adjacent cards.

Quick-start answers for building your sovereign AI node.

I have $5K, what do I buy?

Start with the 3-card B70 build ($5,800). You'll get 96GB VRAM - enough to run Qwen 72B at Q4_K_M quantization. If budget is tight, start with 2 cards ($1,900) and add more later. The WRX90 board supports up to 7 GPUs, so you can scale incrementally.

I have $10K, what do I buy?

Go for the 5-card B70 build ($7,900) and use the remaining $2,100 for upgrades: add more RAM (256GB DDR5 ECC ~$900), larger NVMe (8TB ~$600), or better cooling (Noctua industrial fans ~$150). You'll have 160GB VRAM for maximum model capacity.

I have $30K, what do I buy?

Build the 5-card B70 ($7,900) and invest the rest in: dual-node setup (two 4-card builds for redundancy), enterprise networking (10GbE switches), UPS backup, or a 4x RTX 6000 Ada setup if you need NVIDIA-specific features.

What model should I run for medical use?

Qwen 72B at Q8_0 quantization is the best choice. It has exceptional medical knowledge, strong reasoning capabilities, and fits in 72GB VRAM (4-card B70 setup). For higher throughput, run Qwen 32B at Q8_0 (32GB) for faster responses on simpler queries.

How do I set up llama-server on WSL?

1. Install WSL2 with Ubuntu. 2. Install Intel GPU drivers for WSL. 3. Build llama.cpp from source with IPEX-LLM support: cmake -DGGML_SYCL=ON .. 4. Download your GGUF model. 5. Run: llama-server -m model.gguf -c 8192 --host 0.0.0.0 --port 8080. 6. Access via browser at http://localhost:8080.

How do I connect Hermes Agent?

1. Install Hermes Agent via pip: pip install hermes-agent. 2. Configure it to point to your llama-server: set LLM_URL=http://localhost:8080/v1. 3. Enable Mem0 for persistent memory: mem0 init. 4. Define skills (tools) in the Hermes config. 5. Start the agent: hermes start. 6. Connect LTX Desktop to the Hermes API at http://localhost:8000.

Why blower-style GPUs for multi-GPU?

Blower cards pull air from the front and exhaust it directly out the rear of the chassis. In a 4U rackmount with 4+ GPUs, open-air cards would recirculate hot air between cards, causing thermal throttling. Blower cards ensure each card gets cool intake air.

What is the 1-3-5-7 slot strategy?

When installing 4 GPUs in a 7-slot chassis, use slots 1, 3, 5, and 7. This leaves one empty slot between each card, creating an air gap that prevents heat from one GPU from being sucked into the next card's intake. Combined with blower cooling, this is the optimal thermal solution.
