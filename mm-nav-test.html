MM-Nav Component Usage

This page demonstrates how to use the MM-Nav component on any page. The component is loaded via:

<link rel="stylesheet" href="mm-nav-component.css">
<script src="mm-nav-component.js"></script>

Then initialize it with configuration:

document.addEventListener('DOMContentLoaded', function() {
  const mmNav = MMNav({
    brandLabel: "Twin Context",
    menuItems: [
      { id: "home", label: "Home", url: "#home" },
      { id: "about", label: "About", url: "#about" },
      { id: "contact", label: "Contact", url: "#contact" }
    ],
    onNavigate: function(pageId) {
      // Handle page navigation
      showPage(pageId);
    }
  });
});

This is the home page. The MM-Nav component is now reusable across multiple pages.

Key features:

  • Responsive design
  • URL hash navigation (#home, #about, etc.)
  • Browser back/forward support
  • Customizable menu items
  • Active state highlighting
  • Hover effects

About Page

The MM-Nav component can be configured with different menu items, labels, and URLs.

It injects CSS and HTML automatically, and provides an API for programmatic control.

Navigation between pages is handled via hash URLs (#contact, etc.).
