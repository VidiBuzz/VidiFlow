# Smart Stack Builder App

**Project:** <span style="font-family: 'Kumbh Sans', sans-serif; font-weight: bold;">VidiSmart</span> Master Tech Stack Database & UI  
**Overview:** The <span style="font-family: 'Kumbh Sans', sans-serif; font-weight: bold;">VidiSmart</span> Master Tech Stack from a static HTML file into a dynamic, database-driven application integrated with vidiflow and vidi.news. This system supports over 500 technologies across 21 categories.

## Architecture

*   **Database:** PostgreSQL (via Supabase)
*   **API:** Next.js App Router API Routes
*   **Frontend:** React + TypeScript + Tailwind CSS
*   **Search Engine:** PostgreSQL Full-Text Search with GIN indices
