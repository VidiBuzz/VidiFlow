GSAP

Scroll-Triggered & Timeline Animations

GSAP excels at UI animations, scroll effects, and precise timeline control

Scroll Reveal
Elements fade and slide in as you scroll. Perfect for section reveals.
gsap.from('.scroll-box', { opacity: 0, y: 50, duration: 1, scrollTrigger: { trigger: '.scroll-box', start: 'top 80%' } });
0

Counter Animation
Animated number counters that increment when visible. Great for stats.
gsap.to('.counter', { textContent: 50000, duration: 2, snap: { textContent: 1 }, scrollTrigger: { trigger: '.counter', start: 'top 80%' } });
Stagger Effect
Animate multiple elements with a staggered delay. Perfect for lists and grids.
gsap.from('.stagger-box', { scale: 0, opacity: 0, duration: 0.5, stagger: 0.1, repeat: -1, yoyo: true });
Path Morphing
Smoothly morph between different shapes. Great for icon transitions.
gsap.to('#morph-path', { attr: { d: 'M75 10 Q140 75 75 140 Q10 75 75 10' }, duration: 2, repeat: -1, yoyo: true, ease: 'power1.inOut' });
