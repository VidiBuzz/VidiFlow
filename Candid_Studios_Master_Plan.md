## PAGE ARCHITECTURE & CONTENT MODELING

### Architecture Terminology

This system uses **Content Modeling** - the practice of defining data types and relationships in a CMS for scalable, maintainable websites. Also referred to as:
- **Structured Content Architecture**
- **Entity-Relationship Design**  
- **Dynamic Content Generation**
- **Multi-Entity Architecture**

### Custom Post Type (CPT) Structure

**CRITICAL:** We need **7 separate CPTs**, not one. Each entity type requires distinct field groups, templates, and schema markup.

| CPT Name | Count | Post Type Slug | Purpose | URL Structure |
|----------|-------|---------------|---------|---------------|
| **City Hubs** | 14 | `city_hub` | Geographic landing pages | `/denver`, `/miami` |
| **City Services** | 364 | `city_service` | Location-specific service pages | `/denver/wedding-photography` |
| **National Services** | 26 | `national_service` | Authority pages for core services | `/wedding-photography` |
| **Venues** | 200+ | `venue` | Venue-specific targeting | `/venues/the-breakers-palm-beach` |
| **Team Members** | 30-40 | `team_member` | E-E-A-T authority | `/team/john-doe` |
| **Vendors** | 50+ | `vendor` | Partner network | `/vendors/miami-floral-design` |
| **States** | 6 | `state` | Geographic organization | `/colorado-photography` |

## SCHEMA MARKUP IMPLEMENTATION

### Schema Types by Page

| Page Type | Primary Schema | Secondary Schema |
|-----------|---------------|------------------|
| City Hubs | LocalBusiness | FAQPage, ImageGallery, AggregateRating |
| City Services | Service | LocalBusiness (nested), FAQPage |
| National Services | Service | FAQPage, ImageGallery, HowTo |
| Venues | Place/EventVenue | ImageGallery, Review |
| Team Members | Person | ImageGallery, Review |
| Vendors | LocalBusiness | AggregateRating |
| All Pages | WebPage | BreadcrumbList |

### Required Schema Properties

**LocalBusiness:**
- @type: LocalBusiness
- name
- description
- url
- telephone
- address (PostalAddress)
- geo (GeoCoordinates)
- openingHours
- image
- priceRange

**Service:**
- @type: Service
- name
- description
- provider (LocalBusiness)
- areaServed
- hasOfferCatalog
- image

**Person:**
- @type: Person
- name
- jobTitle
- worksFor (Organization)
- knowsAbout
- alumniOf
- sameAs (social profiles)
- image

**FAQPage:**
- @type: FAQPage
- mainEntity (Question array)
  - @type: Question
  - name (question text)
  - acceptedAnswer (Answer)
    - @type: Answer
    - text (answer text)
