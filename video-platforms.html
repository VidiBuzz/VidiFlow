Self-Hosted Open Source Platforms

PeerTube

AGPL-3.0

Federated video platform using ActivityPub. P2P streaming reduces bandwidth costs. Full plugin system for extending functionality. No ads, no tracking.

Federation P2P Streaming HLS Plugins Live Streaming
Website GitHub Documentation

MediaCMS

AGPL-3.0

Modern YouTube clone built with Django + React. HLS adaptive streaming, automatic transcoding, REST API. Perfect for Python-based LLM integration with Qwen 3.

Django/Python React Frontend REST API Whisper Transcription Docker
Website GitHub Demo

Ghost

MIT

Professional publishing platform with native memberships, subscriptions, and newsletters. Video embeds via Mux, YouTube, or custom. Beautiful editor, fast performance.

Native Memberships Stripe Payments Newsletters Headless API Themes
Website GitHub Documentation

ClassroomIO

AGPL-3.0

Open-source LMS with modern Svelte UI. Built-in AI features for course generation. Video courses, quizzes, analytics, and student management. Stripe payments included.

Svelte UI AI Course Builder Quizzes Analytics Stripe
Website GitHub Documentation

Owncast

MIT

Self-hosted live streaming server. Single binary Go application. RTMP ingest, HLS output, built-in chat. Works with OBS, Streamlabs, and any RTMP source.

Live Streaming RTMP Built-in Chat Go Backend Single Binary
Website GitHub Demo

Open edX

AGPL-3.0

Full enterprise LMS platform used by Harvard, MIT, and thousands of institutions. Video courses, certificates, forums, mobile apps. Complex but comprehensive.

Enterprise LMS Certificates Forums Mobile Apps Tutor Deploy
Website GitHub Documentation

Kaltura CE

AGPL-3.0

Enterprise video platform with Community Edition. Transcoding, analytics, live streaming, DRM. Complex deployment but powerful features for large organizations.

Enterprise Transcoding Analytics DRM API

MIT

Decentralized video platform on LBRY blockchain. Creator monetization via crypto, tips, and memberships. Censorship-resistant content distribution.

Local LLM Integration Stack (Qwen 3 + Qdrant + LangGraph)

Ollama + Qwen 3

Run ollama run qwen2.5:32b locally. Provides fast inference for content generation, summarization, and smart media creation.

Qdrant Vector DB

Store video embeddings for semantic search. Docker: qdrant/qdrant. REST API at port 6333. Perfect for content recommendation.

LangGraph Agents

Build stateful agents for video processing workflows. pip install langgraph. Create custom tools for transcription, tagging, and analysis.

GraphRAG (Microsoft)

Use graphrag-local-ollama fork for knowledge graph extraction from video transcripts. Enables complex Q&A over course content.
