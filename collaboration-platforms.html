All-in-One Collaboration Platforms

Huly

EPL-2.0

Complete Slack + Asana + Notion replacement. Built-in video conferencing via LiveKit, real-time collaboration, CRM, HRM, and ATS modules. Beautiful Svelte UI.

Video Calls Real-time CRM Kanban Svelte
Website GitHub Self-Host

Plane

AGPL-3.0

Modern open-source Jira alternative. Issue tracking, cycles (sprints), modules, roadmaps, and Pages with AI. Beautiful UI built with Next.js and Django.

Issues Cycles Modules AI Pages Analytics
Website GitHub Documentation

AppFlowy

AGPL-3.0

Open-source Notion alternative. Native desktop app with AI workspace. Flutter + Rust for blazing speed. 100% data control with local-first architecture.

AI Built-in Local-First Flutter Rust Cross-Platform
Website GitHub Documentation

Agile Project Management

Taiga

MPL-2.0

Beautiful agile project management for cross-functional teams. Scrum and Kanban boards, epics, user stories. By Kaleidos (same team as Penpot).

Scrum Kanban Epics Python/Django Angular
Website GitHub Community

Leantime

AGPL-3.0

Project management for non-project managers. Built for ADHD, dyslexia, and autism. Strategy, planning, and execution combined. Trello simplicity + Jira features.

ADHD-Friendly Strategy Canvas Time Tracking Retrospectives PHP
Website GitHub Documentation

OpenProject

GPL-3.0

Enterprise project management with German engineering. Gantt charts, agile boards, time tracking, cost reporting, wikis, forums. GitHub integration built-in.

Enterprise Gantt GitHub Integration Time Tracking Ruby
Website GitHub Documentation

Vikunja

AGPL-3.0

Open-source, self-hostable to-do app. Kanban, Gantt, calendar views. Lightweight Go backend, Vue.js frontend. Great for personal and team task management.

Lightweight Go Backend Vue.js CalDAV API
Website Gitea Documentation

Kanban & Task Management

Focalboard

MIT

Open-source alternative to Trello, Notion, and Asana. Desktop app available for Mac, Windows, Linux. Community-maintained since Mattermost archived it.

Desktop App Kanban Table View Go Backend React
Website GitHub Documentation

Wekan

MIT

Open-source kanban board. Meteor.js stack with real-time updates. Swimlanes, WIP limits, due dates, checklists. Simple Trello alternative.

Kanban Swimlanes WIP Limits Meteor.js Real-time
Website GitHub Wiki

Planka

AGPL-3.0

Elegant Trello-like kanban board. Real-time updates with Socket.io. Clean React UI, Node.js backend. Focus on simplicity and speed.

Kanban Real-time React Node.js PostgreSQL
Website GitHub Documentation

AI Integration Stack for Collaboration Platforms

n8n Workflows

Connect your collaboration platform to AI via n8n. Auto-create tasks from emails, generate summaries, smart categorization.

Ollama + Local LLM

Run Qwen 3 or Llama 3 locally for AI task generation, meeting summaries, and code review assistance.

MCP Servers

Use Claude Code's MCP protocol to connect AI directly to your project management tools via custom servers.

GitHub Integration

Most platforms offer GitHub integration. Link issues, PRs, and commits directly to tasks for developer workflows.
