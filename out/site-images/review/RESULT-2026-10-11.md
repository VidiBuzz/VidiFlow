## Changes made to agy-batch-2026-10-11.ps1 (before running)

1. Added print-mode flags to the agy call: `--dangerously-skip-permissions` and
   `--print-timeout <PrintTimeout>` (default `8m`), so print mode cannot hang waiting for approval.
2. Resolved the full agy path once with `(Get-Command agy).Source` and passed it into `Start-Job`,
   and the job now `Set-Location`s to the output dir (PATH / cwd can differ inside a job).
3. Broadened the quota regex to catch `429`, `quota`, `resource_exhausted`/`resource exhausted`,
   `exhausted`, `rate limit`, `too many requests`; on match it logs `quota-stop` and `break`s the loop.
4. Image finder now prefers the requested destination path if agy wrote there, otherwise takes the
   newest image in the brain folder written after the job start time.
5. Non-PNG sources are now really converted to PNG with Pillow (not renamed). If conversion fails the
   raw file is copied and the log records it.
6. Added `-PrintTimeout` and `-PythonExe` parameters; header comment updated.
