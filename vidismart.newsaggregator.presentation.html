Content Workflow

From signal detection to published content

📡

1. Signal Detection

FreshRSS detects new item → Webhook fires to LangGraph orchestrator

🕷️

2. Content Scraping

Crawl4AI fetches full text and media, cleaning HTML to optimized markdown

🧠

3. AI Analysis

Qwen 3 VL MoE generates summary, tags, and "Viral Score" prediction

📐

4. Embedding

BGE-M3 vectorizes the summary for semantic search in Qdrant

👤

5. Human Curation

Content appears in Directus as "Ready for Review". Editor tweaks and approves.

🚀

6. Publish

Directus Flow updates status to published. Next.js revalidates path instantly.
