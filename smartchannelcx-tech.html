System Architecture

Smart Channel CX: An AI-Native Video Orchestration Platform.
Designed for zero-egress rendering, multi-agent automation, and frame-accurate collaboration.

Overview AI Agents Tech Stack Integrations Dashboard

Executive Summary

Smart Channel CX brings the power of desktop NLEs (Non-Linear Editors) to the browser by leveraging a distributed multi-agent system. unlike traditional cloud editors that rely on heavy server-side rendering for every preview, we utilize Remotion and WebAssembly for client-side agility, backed by Cloudflare R2 for massive storage scale without egress costs.

Core capabilities: Frame.io-style collaboration, Generative AI for graphics (ComfyUI), and a Visual Vector Omni Search specifically tuned for video content discovery.

Multi-Agent Orchestration

The system comprises 7 specialized autonomous agents, each handling a specific domain of the production pipeline.

AGENT 01

VidiSmart Cloud Editor

The primary interface for 2026. Acts as a co-pilot for the human editor, merging traditional NLE capabilities with browser-native performance. It uses computer vision to prepare the timeline and synchronize AI-generated assets in real-time.

  • Multi-track non-linear editor (NLE) in the browser
  • Automated take selection based on emotional resonance
  • Real-time Agent Chat integration for timeline manipulation
  • Direct link between media folders and Remotion render engine
Remotion React WebGPU
AGENT 02

Media Ingestion

The gateway to the platform. It handles massive file uploads via the TUS protocol, ensuring resume capability for 4K/8K footage. Upon arrival in R2, it triggers an event-driven workflow.

  • Validates MP4/MOV container integrity headers
  • Generates HLS adaptive bitrate streams for smooth playback
  • Extracts EXIF/XMP metadata (Camera model, Lens, FPS)
  • Triggers Whisper API for immediate transcription
FFmpeg.wasm Whisper API S3/R2 SDK
AGENT 03

Graphics Generation

The creative engine powered by ComfyUI. It removes the need for external stock assets by generating brand-compliant visuals on the fly.

  • Context Awareness: Reads video transcript to suggest relevant b-roll
  • Style Transfer: Applies brand color palette to generated assets
  • Dynamic Lower Thirds: Procedurally generates titles based on speaker ID
ComfyUI Stable Diffusion XL Gemini-Pro-Vision
AGENT 04

Collaboration Core

Implements the "Frame.io" standard. It synchronizes state across multiple clients using WebSockets, ensuring frame-accurate commentary.

  • Live Presence: See active cursors of other team members
  • Review Links: Generate secure, expiring URLs for external client review
  • Version Control: Branch/Merge logic (Git-style) for video timelines
Cloudflare Durable Objects WebSockets SQLite (D1)
AGENT 05

Omni Search Index

Videos are traditionally "black boxes" of data. This agent unpacks them into searchable vectors.

  • Visual Vectors: CLIP embeddings for searching "dog dealing poker" inside video
  • Geospatial: Extractor for GPS lookups (integrates with VidiCity)
  • Knowledge Graph: Neo4j mapping of entities (People, Places, Products)
Pinecone Neo4j CLIP-ViT-L/14
AGENT 06

Quality Control

The gatekeeper ensuring broadcast safety. Automates the technical QC process that usually requires a dedicated engineer.

  • Loudness Spec: Checks EBU R128 compliance (-23 LUFS)
  • Color Safety: Detects gamut violations (Rec.709 safe area)
  • Copyright Check: Fingerprints audio against licensed libraries
FFmpeg Filters TensorFlow JS Audible API
AGENT 07

Render Cluster

Handles the final mile. Distributes frame rendering across potentially thousands of concurrent serverless functions to reduce render times from hours to minutes.

  • Lambda Rendering: Parallel processing of video segments
  • Smart Caching: Re-uses previously rendered segments if unchanged
  • Multi-Format: Simultaneous export of MP4, ProRes, and GIF Preview
Remotion Lambda AWS Lambda / CF Workers
