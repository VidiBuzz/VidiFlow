1AI Personalized Sales Videos - Hero

Sendspark Feature Description

Value Proposition: "Shoot just one video. Then, automatically personalize each video for each viewer with AI."

This is the core landing page hero that immediately communicates the AI-powered personalization capability. The design emphasizes simplicity and scale.

Vidimail Implementation Equivalent

  • VidiMail Hero Module: Main landing page for personalized video email campaigns
  • One-to-Many Personalization: Record once, generate thousands of personalized versions
  • Smart Channel CX Integration: Embedded as primary video messaging feature
  • AI Voice & Visual Cloning: Generate personalized greetings and messages at scale
Implementation Notes: The hero should emphasize the time-saving aspect and the AI personalization engine. Include a live demo widget similar to Sendspark's "Get Started Now" CTA that leads to a sample personalized video.

7Add Contacts & Generate Videos

Sendspark Feature Description

Feature: "Import your contacts into Sendspark and click 'Generate Videos' to make personalized videos for each of your prospects."

Contact list interface with columns for name, email, company, role, and URL. Bulk selection and generation capabilities.

Vidimail Implementation Equivalent

  • VidiBlast Contact Manager: Import and manage prospect lists
  • CSV/Excel Import: Bulk upload contacts with custom fields
  • CRM Sync: Direct integration with Smart Channel CX CRM
  • Bulk Generation: Queue system for processing thousands of videos
  • Progress Dashboard: Real-time generation status
  • Segmentation: Group contacts for targeted campaigns
Technical Requirements: Queue management system (Bull/BullMQ), Batch processing, CRM sync API, CSV parsing, Progress tracking WebSocket
