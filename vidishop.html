★ Why Slot Width Matters: Most towers have 7–9 PCIe slots but only 7 physical width slots. A 3-slot GPU physically blocks the adjacent slot — so 4× W7900 (3-slot) would consume 12 slot widths and is impossible in any tower. The W7900 Dual Slot uses 2 slot widths — you can fit 4× in the WRX90E-SAGE SE (4× active PCIe x16). Same VRAM, same TDP — the Dual Slot version is simply the right card for multi-GPU tower builds.

US Wall Circuit Warning
🔌
120V CIRCUIT LIMIT EXCEEDED — NOT BUILDABLE AS-IS
This configuration draws ~W — exceeding the 1,920W continuous safe limit of a 120V/20A US circuit (NEC 80% rule). To run 4× Workstation Edition GPUs you MUST supply 240V/30A (NEMA 14-30) power. Alternatively, switch to Max-Q Edition (300W each) which keeps the 4-GPU config under 1,700W and within 120V/20A.
🔩
GPU Bottom Clearance Warning
4 GPUs in an 8-slot chassis seats GPU 4 flush against the PSU shroud. Blower intake starved — GPU 4 runs 10–15°C hotter. Upgrade to Fractal Define 7 XL (9 slots) for proper clearance.
⚠️
Case / Motherboard Incompatibility
Selected case max form factor is E-ATX. Asus WRX90E-SAGE SE is SSI-EEB (larger) and will NOT fit. Switch to Define 7 XL, Enthoo Pro 2, or SilverStone RM44.
