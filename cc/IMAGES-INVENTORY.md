On Unsplash, click "Download" → "Large size" (or original)

### Step 3: Rename Files
Rename each downloaded file according to the filenames listed above.

### Step 4: Resize/Crop (if needed)

- https://tinypng.com (recommended)

- Target: <500KB per hero image, <200KB for thumbnails

## TROUBLESHOOTING

**Image shows broken icon?**
- Check filename matches exactly (case-sensitive)
- Confirm file is in correct `assets/images/` folder
- Verify file extension is `.jpg` (not .png or .jpeg unless you update code)

**Image too large/slow loading?**
- Compress with TinyPNG
- Resize to actual needed dimensions (don't use 4000px image for 1920px display)

**Want better quality?**
- Search specific hotel names on Google Images (filter for reuse)
- Contact Doug for actual project photos (recommended for launch)
