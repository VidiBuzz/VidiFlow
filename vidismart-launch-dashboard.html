🗄️ CMS & Content Layer

Directus — our headless CMS for pages, Smart Channel CX, and content management

Directus

Headless CMS — Open Source (GPL-3)
✓ CHOSEN

Directus is an open-source headless CMS that wraps any SQL database with a real-time API and an intuitive admin app. We use it to manage all VidiSmart HTML pages, Smart Channel CX content, media assets, and user accounts. It serves as the single source of truth for content across VIDIpitch and VidiSmart.

Headless CMS REST + GraphQL API Real-time Role-based Access File Management Webhook Flows PostgreSQL

PostgreSQL + pgvector

Database + Vector Extension

PostgreSQL is the world's most advanced open-source relational database. The pgvector extension adds native vector similarity search — enabling semantic search, recommendation engines, and AI-powered content discovery directly within our Directus database.

OpenAI Embeddings

text-embedding-3-small / large
✓ CHOSEN

OpenAI's embedding models convert text into 1536-dimensional vectors that capture semantic meaning. We use these to vectorize all content uploaded to Directus, enabling semantic search, content recommendations, and AI agent queries across our knowledge graph.
