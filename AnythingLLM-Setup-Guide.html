⚡ Quick Start for Qwen 3.5

Local Ollama Setup

# Install Qwen 3.5 (latest version)
ollama pull qwen3:8b
# Or for larger model
ollama pull qwen3:14b
# Or for the massive model
ollama pull qwen3:32b

In AnythingLLM UI

  1. Go to Settings → LLM Preferences
  2. Select "Ollama" as provider
  3. Set Base URL: http://localhost:11434
  4. Select Model: qwen3:8b (or 14b/32b)
  5. Test Connection → Save

Qwen3-Embedding-2B Setup

# Pull the embedding model
ollama pull qwen3-embedding:2b
  1. Go to Settings → Embedding Preferences
  2. Select "Ollama" as provider
  3. Set Base URL: http://localhost:11434
  4. Select Model: qwen3-embedding:2b
  5. Test Connection → Save

OpenRouter (Cloud Option)

  • Select "OpenRouter" as provider
  • Get API key from openrouter.ai
  • Use model ID: qwen/qwen3-8b-instruct

MCP (Model Context Protocol) Servers

MCP is an open protocol connecting AI models to external tools.

Server Purpose Setup
Filesystem Local file operations npx -y @modelcontextprotocol/server-filesystem /path
Brave Search Privacy web search Set BRAVE_API_KEY
Tavily Search Deep AI search Set TAVILY_API_KEY
GitHub Repo/issue access Set GITHUB_TOKEN
PostgreSQL Database queries Set POSTGRES_URL
Google Drive Drive file access OAuth setup
Playwright Browser automation npx -y @modelcontextprotocol/server-playwright

Setting Up MCP Servers

  1. Click Settings → MCP Servers
  2. Add Server:
    • Name: brave-search
    • Transport: stdio
    • Command: env BRAVE_API_KEY=your_key npx -y @modelcontextprotocol/server-brave-search
  3. Save → Restart AnythingLLM

📁 File Manager Deep Dive

The built-in file manager is bare bones. You need plugins/integrations to make it usable.

Option 1: Paperless-ngx Integration (RECOMMENDED)

Provides proper document management with OCR, tagging, and automatic ingestion.

# docker-compose.paperless.yml
version: '3.8'
services:
  paperless:
    image: ghcr.io/paperless-ngx/paperless-ngx:latest
    ports:
      - '8090:8000'
    volumes:
      - paperless_data:/data
      - paperless_media:/media
      - ./documents:/documents  # Your intake folder
    environment:
      PAPERLESS_URL: http://localhost:8090
      PAPERLESS_SECRET_KEY: your_random_secret
      OCR_LANGUAGE: eng
      PAPERLESS_CONSUMER_RECURSIVE: "true"
    restart: unless-stopped

volumes:
  paperless_data:
  paperless_media:

Workflow: Drop docs → Paperless OCRs & tags → Export to AnythingLLM

Option 2: File System MCP (PRIMARY FILE MANAGER)

This is your main file manager interface - browse, search, and manage local files.

Step 1: Install Filesystem MCP

  1. Settings → MCP Servers → Add Server
  2. Configure:
    • Name: local-filesystem
    • Transport: stdio
    • Command: npx -y @modelcontextprotocol/server-filesystem C:\Users\You\Documents C:\Users\You\Projects
  3. Save → Restart AnythingLLM

Step 2: Using the File Manager

Once connected, use @agent commands:

@agent List all files in my Documents folder
@agent Search for files containing "contract" in Projects
@agent Read the file at C:\Users\You\Documents\report.pdf
@agent Show me the folder structure of Downloads

Step 3: Auto-Upload Script (Optional)

# auto-upload-watchdog.py
import os, time, requests
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

WATCH_FOLDERS = [
    "C:\\Users\\You\\Documents\\Scan-Inbox",
    "C:\\Users\\You\\Downloads\\To-Process"
]

class DocumentHandler(FileSystemEventHandler):
    def on_created(self, event):
        if not event.is_directory:
            print(f"📄 New file: {event.src_path}")
            # Auto-upload to AnythingLLM

if __name__ == "__main__":
    observer = Observer()
    for folder in WATCH_FOLDERS:
        observer.schedule(DocumentHandler(), folder, recursive=True)
    observer.start()

Option 3: Google Drive MCP (CLOUD FILE MANAGER)

Use this for cloud-based file management and team collaboration.

Step 1: Google Cloud Console Setup

  1. Go to console.cloud.google.com
  2. Create new project → "AnythingLLM-Integration"
  3. Enable Google Drive API:
    • APIs & Services → Library → Search "Google Drive API" → Enable
  4. Create OAuth Credentials:
    • APIs & Services → Credentials → Create Credentials → OAuth client ID
    • Application type: "Desktop app"
    • Name: "AnythingLLM Drive"
    • Download the client_secret.json file

Step 2: Install Google Drive MCP

  1. Settings → MCP Servers → Add Server
  2. Configure:
    • Name: google-drive
    • Transport: stdio
    • Command: npx -y @modelcontextprotocol/server-gdrive
  3. On first run, authenticate with Google OAuth
  4. Save → Restart AnythingLLM

Step 3: Using Google Drive as File Manager

@agent List files in my Google Drive root
@agent Search Drive for "budget spreadsheet"
@agent Read the document "Q4 Report" from Google Drive
@agent Show me files in Drive folder "Projects/Active"
@agent Download "contract.pdf" from Drive to local
Pro Tip: Combine both File System and Google Drive MCPs for maximum flexibility. Use Paperless only for initial document intake/OCR.

👥 Team Sharing & Multi-User Setup

Docker Deployment for Teams

version: '3.8'
services:
  anythingllm:
    image: mintplexlabs/anythingllm:latest
    container_name: anythingllm-team
    ports:
      - "3001:3001"
    volumes:
      - anythingllm-storage:/app/server/storage
    environment:
      - SERVER_PORT=3001
      - STORAGE_DIR=/app/server/storage
      - JWT_SECRET=change-this-to-32-char-random-string
      - AUTH_TOKEN=change-this-to-32-char-random-string
      - LLM_PROVIDER=ollama
      - OLLAMA_BASE_PATH=http://host.docker.internal:11434
      - OLLAMA_MODEL_PREF=qwen2.5:7b
      - VECTOR_DB=qdrant
      - QDRANT_ENDPOINT=http://qdrant:6333
    restart: unless-stopped
    
  qdrant:
    image: qdrant/qdrant:latest
    volumes:
      - qdrant-storage:/qdrant/storage
    ports:
      - "6333:6333"

volumes:
  anythingllm-storage:
  qdrant-storage:

Network Access

Setup URL
Local http://localhost:3001
Network http://<server-ip>:3001
With Domain Use Nginx reverse proxy

Security Checklist

  • Change JWT_SECRET (32+ characters)
  • Set AUTH_TOKEN
  • Disable signups after setup: DISABLE_SIGNUPS=true
  • Use HTTPS in production
  • Regular backups of storage folder

Key API Endpoints

# Upload document
curl -X POST http://localhost:3001/api/v1/document/upload \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@document.pdf"

# Chat with workspace
curl -X POST http://localhost:3001/api/v1/workspace/my-workspace/chat \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message": "Summarize documents"}'

📝 AppFlowy Integration

Limitation: AppFlowy does NOT have a public REST API for document creation. Requires workarounds.

Recommended Pattern

AnythingLLM Chat → Export Markdown → Import to AppFlowy

Option 1: Manual Export (Simplest)

  1. In AnythingLLM: Copy chat output
  2. Paste into markdown file
  3. Drag into AppFlowy

Option 2: Python Automation Script

# save_chat_to_appflowy.py
import os
from datetime import datetime

CHAT_EXPORT_DIR = "C:/Users/You/AppFlowy/Chat-Imports"

def save_chat(chat_content, title="Chat Session"):
    filename = f"{datetime.now().strftime('%Y-%m-%d_%H-%M')}_{title}.md"
    filepath = os.path.join(CHAT_EXPORT_DIR, filename)
    
    with open(filepath, 'w', encoding='utf-8') as f:
        f.write(f"# {title}\n\n{chat_content}")
    
    print(f"Saved to: {filepath}")
    # Drag this file into AppFlowy

Option 3: Advanced (Database Integration)

AppFlowy stores data in SQLite with Collab/Yrs CRDT format. Requires modifying AppFlowy's Rust codebase.
