Step-by-Step Logic

The complete RAG pipeline in action

1

Ingest & Intent Classification

Qwen-7B-Router analyzes the query and classifies intent: LOCAL_EVENT + GEO:Austin. Determines which search tools to activate.

Intent: LOCAL_EVENT | Geo: Austin | Tools: [qdrant, swirl]
2

Parallel Retrieval

Execute both Qdrant vector search and Swirl federated search simultaneously. Maximum coverage, minimum latency.

Promise.all([qdrantSearch(query), swirlSearch(query)])
3

Rerank & Merge

Jina-Reranker-v2 normalizes scores from both sources. Outputs a single, ordered list of the Top 8 most relevant text chunks.

jinaRerank(chunks, topK=8) → unified_context[]
4

Smart Answer Generation

Qwen 3 VL MoE synthesizes a succinct, citation-backed summary. "You are Vidi, a helpful city guide..."

Qwen3-VL-235B → Response with [1][2][3] citations
