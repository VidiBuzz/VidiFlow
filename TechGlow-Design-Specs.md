## How to Apply to Google Slides

### Method 1: Manual Application (Recommended)
1. Create new Google Slides presentation
2. Go to **Slide → Edit master**
3. Upload background images from `/mnt/m/code/vidismart/techglow_design_extracted/`
4. Set slide background to use extracted gradient images
5. Set fonts: Inter (primary), Kumbh Sans, Lato
6. Color scheme: Purple (#690be5), Black, Dark Grays

### Method 2: Use Extracted Backgrounds
The following background images are ready to use:
- `slide_01_image_01.png` - Main gradient (1920x1094)
- `slide_02_image_01.png` - Alt gradient (1896x1080)
- `slide_10_image_00.png` - Full slide gradient (1920x1080)

### Typography Settings for Google Slides
```
Heading 1: Inter, 44pt, Bold, #000000
Heading 2: Inter, 32pt, Bold, #000000
Body: Inter, 16pt, Regular, #404040
Accent: Kumbh Sans, Various sizes, #690be5
```

### Gradient Background Recreation
If you want to recreate the gradients in Google Slides:
1. **Base Color**: Dark purple/violet (#690be5)
2. **Gradient Direction**: Diagonal (top-left to bottom-right)
3. **Gradient Stops**:
   - Start: Deep purple #690be5
   - Middle: Blue-purple blend
   - End: Dark blue/black
