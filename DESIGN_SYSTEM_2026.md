# VidiSmart 2026 "Smart Stack" Design System
**Version 1.0 - Live Agents Dashboard**

## 1. Core Engineering Philosophy ("Smart Stack")
The design reflects a "Glass & Metal" aesthetic—high-tech, transparent, and built on a solid underlying structure. It combines the clean, breathable nature of **Glassmorphism** with strong, dark **Industrial/Data** backgrounds.

---

## 2. Technical Implementation Rules (CRITICAL)
**Lesson Learned (Jan 2026):**
Do *not* rely solely on external Tailwind scripts for critical layout grids. If the script fails or is removed, the layout collapses.
*   **Best Practice:** Use **Vanilla CSS Grid** for main structural columns.
*   **Grid Template:**
    ```css
    .dashboard-grid {
        display: grid;
        grid-template-columns: 1fr 1fr; /* Force 50/50 split */
        gap: 1.5rem;
        width: 100%;
        max-width: 1600px; /* Max safe width */
    }
    ```

### B. Typography
*   **Headings:** `Kumbh Sans` (Weights: 700, 800, 900) - Tight tracking (`-0.02em`).
*   **Body:** `Inter` (Weights: 400, 500) - High legibility.
*   **Labels/Badges:** Uppercase, tracked out (`tracking-widest`), small text (`text-[10px]`).

### C. Color Palette
*   **Primary Accent:** Amber/Orange (`#B45309`) - Represents "Electricity/Action".
*   **Secondary:** Deep Blue (`#1e3a8a`) - Represents "Enterprise/Trust".
*   **Backgrounds:** Deep Dark (`#111827`) or Light Off-White (`#FAF9F6`).

---

## 4. Layout & Spacing
*   **Margins:** Always ensure `px-6` or `px-12` margins on large containers (`max-w-screen-2xl`). Never let content touch the edge.
*   **Vertical Rhythm:** Use `gap-4` (1rem) for tight modules and `gap-8` (2rem) for major sections.

## 5. Visual Agents (VidiTwin)
*   **Presentation:** Always display video feeds in a **2x2 Grid** ("Four Square") to mimic a meeting interface.
*   **Ratio:** Cards should hold compact proportions, avoiding excessive vertical whitespace (`h-fit`).
