On unified memory (DDR5) vs VRAM: You can run larger models on DDR5 system RAM via llama.cpp CPU offload, but expect 6–9× slower tokens/sec than GPU inference — DDR5 bandwidth is ~100 GB/s vs GDDR6X at ~900 GB/s. A 160 GB DDR5 workstation can run Qwen 3.5 72B (~44 GB model weight) but you're trading speed for accessibility. For production use on Vidi AI™, pure VRAM is always preferred.
