01. Executive Summary

Mission: Build Smart Channel CX, a browser-based video editing platform with Frame.io-style collaboration, powered by AI/ML pipelines and integrated with the existing Vidi ecosystem (VidiFlow, VidiShop, VidiCity, Visual Vector Omni Search).

Project Vision

Smart Channel CX represents the convergence of professional video editing, AI-powered content generation, and intelligent search capabilities. The platform enables users to edit MP4 files directly in the browser while leveraging a powerful media pool stored in Cloudflare R2, with real-time collaboration features inspired by Frame.io.

Key Capabilities

  • Browser-Based Video Editing: Full MP4 editing (trim, cut, split, transitions, text overlays, audio mixing, filters) powered by Remotion
  • AI-Powered Effects: Integration with ComfyUI and Stable Diffusion for generative video effects
  • Smart Graphics Generation: Gemini API integration for automated graphics and thumbnail creation
  • Visual Vector Omni Search: BM25 + Vector + Graph RAG + Geospatial search for content discovery
  • Frame.io-Style Collaboration: Time-stamped comments, version control, review workflows
  • Multi-Brand Support: VidiShop integration for personalized shopping experiences
  • Local News Portal: VidiCity geospatial video news platform integration
  • Knowledge Base: AppFlowy (VidiFlow) integration for faceted content creation

Target Users

  • Content creators and video editors
  • Marketing teams managing video campaigns
  • Local news organizations (VidiCity)
  • E-commerce businesses (VidiShop)
  • Agencies requiring client collaboration

Agent Definitions

📥

Agent 01: Media Ingestion Agent

media-ingestion-agent

Responsibilities:

  • Handle MP4 uploads to Cloudflare R2 via presigned URLs
  • Extract metadata (duration, resolution, codec)
  • Generate multiple resolution variants (1080p, 4K)
  • Create thumbnail sprites for timeline preview
  • Transcode to browser-compatible formats
  • Trigger transcription for caption generation

Tools: FFmpeg.wasm, Whisper API, R2 SDK

Triggers: Webhook on upload complete

✂️

Agent 02: Edit Assistant Agent

edit-assistant-agent

Responsibilities:

  • Process edit operations (trim, cut, split, merge)
  • Build edit decision lists (EDL) from user actions
  • Optimize render pipelines
  • Suggest edit points using scene detection
  • Apply smart transitions based on content analysis

Tools: Remotion Player, Scene Detection ONNX Model

Triggers: User edit actions, auto-save intervals

🎨

Agent 03: Graphics Generation Agent

graphics-gen-agent

Responsibilities:

  • Generate AI-powered graphics from text prompts
  • Create animated lower thirds and titles
  • Generate thumbnail variations for A/B testing
  • Apply style transfer and visual effects via ComfyUI
  • Create branded templates for VidiShop products

Tools: Gemini API, ComfyUI API, Stable Diffusion

Triggers: User prompt submission, template selection

💬

Agent 04: Collaboration Agent

collaboration-agent

Responsibilities:

  • Manage Frame.io-style comments with timecodes
  • Handle real-time collaboration sessions
  • Track version history and branching
  • Route notifications to team members
  • Generate share links with permissions

Tools: WebSockets, Cloudflare D1, Notification Service

Triggers: Comment posts, version saves, share actions

🔍

Agent 05: Search Index Agent

search-index-agent

Responsibilities:

  • Extract visual embeddings from video frames
  • Index spoken content via transcription
  • Build knowledge graphs from content relationships
  • Enable geospatial tagging for VidiCity integration
  • Update vector indices in real-time

Tools: CLIP Model, Neo4j, Pinecone/Weaviate, PostGIS

Triggers: Video processing complete, metadata updates

✅

Agent 06: Quality Control Agent

quality-control-agent

Responsibilities:

  • Validate export settings for target platforms
  • Check for audio/video sync issues
  • Verify color space and HDR compliance
  • Detect potential copyright issues in audio
  • Ensure accessibility standards (captions, descriptions)

Tools: FFmpeg validation, Audio fingerprinting ONNX models

Triggers: Export request, pre-publish checks

🎬

Agent 07: Export Render Agent

export-render-agent

Responsibilities:

  • Queue and manage render jobs
  • Distribute rendering across worker nodes
  • Apply final compositing and effects
  • Generate multiple output formats simultaneously
  • Deliver to R2 and trigger distribution workflows

Tools: Remotion Lambda, FFmpeg, R2 SDK

Triggers: Export button click, scheduled renders

04. Technology Stack

Frontend Layer

⚛️ Next.js 14 (App Router)

React framework with server components, streaming SSR, and edge runtime support. Handles the video editor UI and real-time collaboration features.

🎬 Remotion

Programmable video editing in React. Core engine for timeline, preview, and rendering. Templates: Recorder, Overlay, Next.js integration.

🎨 TailwindCSS + Framer Motion

Utility-first styling and animations for the editor interface. Frame.io-inspired dark theme with smooth interactions.

📹 FFmpeg.wasm

Browser-based video processing for client-side operations, thumbnail generation, and format validation.

Edge & Serverless Layer

☁️ Cloudflare Workers

Edge compute for API routing, authentication, and real-time WebSocket handling. Deployed globally for minimal latency.

🦀 Rust + Astro

High-performance API gateway and compute services. WASM-compatible for running ONNX models at the edge.

🗄️ Cloudflare D1

SQLite-based edge database for projects, user data, and collaboration state. Replicated globally.

⚡ Cloudflare KV

Key-value store for session data, cache, and real-time collaboration state.

Storage & CDN

📦 Cloudflare R2

S3-compatible object storage for video files, assets, and renders. Zero egress fees, ideal for media delivery.

🌐 Cloudflare CDN

Global content delivery for video segments, thumbnails, and static assets. Smart caching strategies.

🔄 TUS Protocol

Resumable upload protocol for large video files. Enables pause/resume and parallel chunk uploads.

AI/ML Services

🧠 ComfyUI

Node-based Stable Diffusion interface for AI video effects, style transfer, and generative graphics.

🔮 Google Gemini API

Multimodal AI for graphics generation, content analysis, and automated editing suggestions.

⚙️ ONNX Runtime

Cross-platform ML inference for scene detection, object recognition, and quality analysis models.

🎯 CLIP/BLIP Models

Vision-language models for content understanding, auto-captioning, and visual search indexing.

Search & Analytics

📊 Visual Vector Omni Search

Custom search layer combining multiple paradigms for the Vidi ecosystem.

🔍 Meilisearch/Typesense

BM25 keyword search with typo tolerance, faceting, and instant search capabilities.

🧮 Pinecone/Weaviate

Vector database for semantic similarity search on video embeddings.

🕸️ Neo4j

Graph database for RAG implementations, content relationships, and recommendation engines.

🗺️ PostGIS

Geospatial extension for VidiCity location-based video search and mapping.

Integrations

🔐 Clerk Auth

Authentication and user management with SSO support for enterprise clients.

💳 Stripe

Subscription billing, usage-based pricing, and team plan management.

📝 AppFlowy API

Integration with VidiFlow knowledge base for content research and scripting.

🛒 Shopify/VidiShop

E-commerce integration for shoppable videos and product tagging.
